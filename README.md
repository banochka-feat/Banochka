# 🫙 Баночка — копилка

Веб-приложение для iPhone: записывай, сколько и когда ты отложил, и смотри, как растут накопления.

- Сумма в баночке и цель с прогрессом
- История вложений по месяцам: дата, время, сумма, комментарий
- График роста накоплений
- Светлая и тёмная тема, работает без интернета
- Резервная копия данных (меню «•••»)

## Как установить на iPhone

1. Открой ссылку на приложение в **Safari**.
2. Нажми **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»**.
3. На экране появится иконка «Баночка».

Данные хранятся только на телефоне. Время от времени сохраняй резервную копию через меню «•••».
